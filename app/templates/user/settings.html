📖 Userscript Installation Steps

  1. Install the free Tampermonkey extension in your browser.
  2. Open the Userscript file located at /userscript/coinvault-verifier.user.js and copy its code.
  3. Create a new script in Tampermonkey and paste the code.
  4. Navigate to your authorized eFootball balance page; click the floating HUD gear (⚙) icon.
  5. Paste your generated API Bearer token and click Save Configuration.
Note: The companion script relies on DOM reading. If Konami changes their webpage layout, simply update the CSS selector in the script settings.
